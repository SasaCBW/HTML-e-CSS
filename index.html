HTML

index.html

É a página principal. Define os conteúdos, títulos, textos, links e a organização dos elementos.

CSS

style.css

Controla as cores, fontes, tamanhos, espaçamentos, posicionamento e adaptação para diferentes telas.

JS

app.js

Adiciona comportamentos, como abrir o menu, validar respostas e calcular a pontuação do quiz.

IMG

assets/images/

Guarda as imagens do projeto, deixando os recursos visuais organizados em uma pasta própria.

NA PRÁTICA

Conectando HTML e CSS

HTML
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Meu projeto</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Meu primeiro projeto</h1>
  <p>Estrutura e estilo trabalhando juntos.</p>
  <script src="js/app.js" defer></script>
</body>
</html>
ⓘ Os caminhos em href e src devem corresponder aos nomes e pastas reais do projeto.
